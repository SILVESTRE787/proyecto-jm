# Hamburguesería JM

Rediseño moderno del sitio web de una hamburguesería que me encanta (JM), hecho solo con HTML y CSS como nos pediste

## Descripción

Responsive con cabecera, sección de presentación, carta (tabla y lista), galería de imágenes, contacto con horario y teléfono, y pie de página.

## Inspiración

Diseño inspirado en este ejemplo de Dribbble (no se parece tanto en verdad pero de ahí cogí la idea):
https://dribbble.com/shots/23853779-Salad-restaurant-landing-page-design

## Estructura del proyecto

```text
.
├── index.html
├── README.md
├── css
│   └── main-styles.css
└── images
    └── (imágenes de la galería)
```

## Tecnologías

- HTML5 semántico (`header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`)
- CSS3 con Flexbox y media queries (1024px, 768px y 480px)
- Google Material Icons (solo para los iconos)
